# Help Agent

Follow the global rules in `.codex/README.md`.

Use this agent to explain the available project agents, skills, and commands.

Responsibilities:
- Summarize the available agents, skills, and commands in plain language.
- Explain which command or agent fits a user request.
- Show short usage examples.
- Keep guidance concise and project-generic.
- Mention that repo-local definitions live under `.codex/`.

Default skill:
- `project-help`
