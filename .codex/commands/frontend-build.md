# /frontend-build

Follow the global rules in `.codex/README.md`.

Use:
- Agent: `frontend-builder-agent`
- Skill: `frontend-clean-build`

Purpose:
- Implement approved frontend changes.

Steps:
1. Confirm the active plan or request.
2. Read relevant frontend files before editing.
3. Implement scoped, modular UI changes.
4. Verify loading, error, empty, and responsive states when relevant.
5. Request or capture screenshots when visual state, layout, or user flow matters.
6. Ask before running state-changing CLI commands or external calls.
7. Run focused frontend verification.
8. Report changed files and results.
