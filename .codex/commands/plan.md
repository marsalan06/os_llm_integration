# /plan

Follow the global rules in `.codex/README.md`.

Use:
- Agent: `planner-agent`
- Skill: `project-planning`

Purpose:
- Plan a feature, bug fix, refactor, investigation, or operational task before implementation.

Steps:
1. Read relevant instructions, docs, and code.
2. Restate the goal.
3. Identify assumptions, risks, affected files, and verification.
4. Split the work into modular phases.
5. Define implementation and testing checkpoints for each phase.
6. Produce an approval-ready plan.
