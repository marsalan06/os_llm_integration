# /review

Follow the global rules in `.codex/README.md`.

Use:
- Agent: `reviewer-agent`
- Skill: `bug-security-review`

Purpose:
- Review code, diffs, plans, or queries for bugs, security risks, regressions, and missing tests.

Steps:
1. Inspect changed files and relevant surrounding code.
2. Lead with severity-ordered findings.
3. Include exact file references where possible.
4. List open questions, assumptions, and test gaps.
